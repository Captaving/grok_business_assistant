# Бизнес-помощник: голосовые от начальника → задачи

Telegram-бот, который тихо слушает твой личный чат с начальником (через «Автоматизацию чатов»),
расшифровывает пачки голосовых, присылает **тебе в личку** сводку и превращает поручения в задачи
с напоминаниями.

- В чат с собеседником бот **ничего не пишет**, только слушает.
- Бот общается **только с владельцем** (`OWNER_ID`), остальных игнорирует.
- Всё бесплатно: Telegram «Автоматизация чатов» (без Premium) + бесплатный тариф [Groq](https://console.groq.com)
  (Whisper для расшифровки, GPT-OSS для сводки).

```
📋 Елена · 28.10 14:02–14:31 · 28 🎤, 2 💬

🧾 Коротко: нужно закрыть отчёт по поставщикам и подготовиться к встрече в пятницу.

✅ Задачи:
1. Отправить отчёт Иванову ⏰ 30.10, четверг ❗
2. Переделать слайды 4–7

❓ Уточнить у руководителя:
— «ну то самое по договору» — какой именно договор?

📎 Полная расшифровка (файлом)

🆕 Задача 1 из 2
📌 Отправить отчёт Иванову
Отчёт по поставщикам, в PDF
💬 «скинь Иванову отчёт до четверга, это срочно»
⏰ Срок: 30.10, четверг
Добавить в задачи?            [✅ Да] [❌ Нет]
```

## Что умеет

**Голосовые → сводка.** Голосовые расшифровываются сразу по приходу. Когда в чате наступает тишина
на `BATCH_DELAY` секунд (по умолчанию 3 минуты), бот присылает сводку и файл с полной расшифровкой.
Пачка из одних текстовых сообщений не сводится, чтобы бот не дёргал тебя на каждое «ок».
Голосовые можно и просто переслать боту.

**Сводка → задачи.** По каждой найденной задаче бот спрашивает «Добавить в задачи?» — ✅ Да / ❌ Нет.

**Задачи.** Кнопка «📋 Задачи» внизу экрана показывает список открытых (сначала срочные и с ближайшим сроком).
В карточке задачи: подробности, цитата начальника, срок и кнопки:

- **✅ Закрыть** — бот подтверждает «Задача закрыта» (если ошибся — «↩️ Вернуть в работу»);
- **⏰ Напомнить** — через 1 час, 3 часа, завтра в 9:00 или через 3 дня. Если к этому времени задача
  не закрыта, бот пришлёт её с теми же кнопками.

**Утренняя сводка.** Каждый день в `DIGEST_TIME` (по умолчанию 09:00): сколько задач открыто,
что просрочено и у чего срок сегодня.

**Свои задачи.** Напиши боту любой текст — он предложит сделать из него задачу. Или сразу: `/add текст`.

## Команды (только для владельца)

| Команда | Что делает |
|---|---|
| `/tasks` | Открытые задачи (то же, что кнопка «📋 Задачи») |
| `/add текст` | Добавить задачу сразу, без вопросов |
| `/today` | Что горит сегодня: просроченное и со сроком на сегодня |
| `/closed` | Недавно закрытые — можно вернуть в работу |
| `/now` | Свести голосовые сейчас, не дожидаясь паузы |
| `/status` | Что сейчас копится в очереди |
| `/help` | Подсказка |

## Установка

### 1. Подготовь ключи

- **Токен бота**: @BotFather → `/newbot`. Затем там же: `/mybots` → бот → Bot Settings → **Business Mode → Turn on**.
- **Ключ Groq**: зарегистрируйся на [console.groq.com](https://console.groq.com) → API Keys → Create. Бесплатно, карта не нужна.
- **Твой Telegram ID**: напиши @userinfobot, он пришлёт число.

### 2. Поставь на сервер (Ubuntu 22.04+ / Debian 12+)

```bash
sudo apt-get update && sudo apt-get install -y git
```

```bash
sudo git clone https://github.com/Captaving/grok_business_assistant.git /opt/voice-summary-bot
```

```bash
sudo bash /opt/voice-summary-bot/install.sh
```

Установщик спросит токен, ID и ключ Groq, проверит их, создаст службу `voice-summary-bot` и запустит её.
Задачи хранятся в `/var/lib/voice-summary-bot/tasks.db` и переживают перезапуски и обновления.

### 3. Подключи бота в Telegram

1. Напиши боту `/start`.
2. Настройки → Изменить профиль → **Автоматизация чатов** → выбери бота.
3. Доступ: **«Только выбранные чаты»** → чат с начальником.
4. Право отвечать на сообщения можно выключить, оно боту не нужно.

Бот напишет «✅ Подключено». Всё, жди голосовые.

## Обслуживание

```bash
journalctl -u voice-summary-bot -f
```

```bash
cd /opt/voice-summary-bot && sudo git pull && sudo bash install.sh
```

Первая команда показывает логи, вторая обновляет бота. При обновлении на вопрос про токены жми Enter, чтобы оставить старые.

Настройки лежат в `/opt/voice-summary-bot/.env` (полный список — в `.env.example`). После правки:

```bash
sudo systemctl restart voice-summary-bot
```

## Важно знать

- Голосовые уходят на расшифровку в Groq (США). Если там что-то совсем секретное — имей в виду.
- Лимиты бесплатного Groq: примерно 20 голосовых в минуту и пара часов аудио в час. Бот сам притормаживает и повторяет запросы.
- Из РФ Groq может быть недоступен, поэтому бот должен жить на зарубежном сервере.
- Пачки голосовых, которые ещё ждут паузы, хранятся в памяти: если перезапустить бота посреди пачки,
  она потеряется (голосовые можно переслать боту руками). Задачи и напоминания хранятся в базе и не теряются.
